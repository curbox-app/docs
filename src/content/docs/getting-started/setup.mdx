Install Curbox from an official source. Then, give Curbox the permissions for the features that you use.

## Install Curbox

Use one of these official sources:

- [F-Droid](https://f-droid.org/)
- [Curbox releases on GitHub](https://github.com/nethical6/curbox/releases/latest)

For the simplest update process, install Curbox with the F-Droid app. You can also download the APK file from GitHub Releases.

<Aside type="danger">
Do not install Curbox from an unofficial source. Curbox uses sensitive Android permissions, and a modified APK can put your data at risk.
</Aside>

### If Android shows a security warning

Android can show a warning for an app that you install outside Google Play. Confirm that you downloaded the APK from the official Curbox GitHub repository.

Do not turn off Play Protect for all apps. Follow the on-screen Android procedure for this APK only.

Some Android versions block accessibility access for a sideloaded app. If Android blocks access, open the Curbox app information screen. Open the menu and tap **Allow restricted settings**. The exact menu can be different on each device.

## Give Curbox the required permissions

Curbox shows its permission setup when you first open the app. Give a permission only when you want to use its related feature.

<Steps>
1. **Allow display over other apps**
   Tap the overlay permission in Curbox. Select **Curbox**, and turn on **Display over other apps**. Curbox uses this permission for warning screens and overlays.

2. **Allow notifications**
   Tap the notification permission. Then, tap **Allow**. Curbox uses a notification to keep an active service visible.

3. **Allow Do Not Disturb access**
   Tap the Do Not Disturb permission. Select **Curbox**, and allow access. Focus Mode and Auto DND use this permission.

4. **Turn on App Blocker Accessibility**
   Tap **App Blocker Accessibility**. Select **Curbox**, and turn on the service. Curbox uses this service to apply blocks and reducers.

5. **Turn on Usage Tracker Accessibility**
   Tap **Usage Tracker Accessibility**. Select **Curbox**, and turn on the service. Curbox uses this service to measure app use.
</Steps>

<Aside type="note">
Android setting names can be different on some devices. Return to Curbox after you give each permission.
</Aside>

## Optional Shizuku setup

Some Curbox features use permissions that Android does not give through the usual settings. Curbox can request these permissions through [Shizuku](https://shizuku.rikka.app/).

The [Grayscale Filter](../../reducers/grayscale/) page contains the Shizuku procedure and an ADB alternative.

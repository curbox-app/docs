The **Usage** screen shows your screen time and your app use. It can also show website and short-form video statistics.

## View app statistics

The **TOTAL TODAY** value shows your total screen time for the current day. The chart below this value shows one bar for each day of the week.

Tap a bar to see the total for that day. Use the arrows to show a different week.

The app list shows the use duration for each app. Scroll down to see all apps.

## View website statistics

Curbox can measure website use in a supported browser. The website statistics appear below the app list and are grouped by browser.

If a browser is not supported, Curbox does not show website statistics for that browser.

## View short-form video statistics

The short-form video section shows these values:

- Number of watched videos
- Total watch duration
- Average attention duration

## Exclude an app

Some background apps can add unwanted data to your statistics.

<Steps>
1. **Open the Usage menu**
   Tap the menu in the upper-right corner of the **Usage** screen.

2. **Open the ignore list**
   Tap **Ignore List**.

3. **Select apps**
   Add each app that you do not want in the statistics.
</Steps>

## Export usage data

<Steps>
1. **Open the Usage menu**
   Tap the menu in the upper-right corner.

2. **Start the export**
   Tap **Export**.

3. **Select an export type**
   Select **Daily Breakdown**, **Total Summary**, or **Both**.

4. **Save the file**
   Select a location for the CSV file.
</Steps>

The export types contain this data:

| Export type | Data |
|---|---|
| **Daily Breakdown** | One row for each app on each day |
| **Total Summary** | One total row for each app |
| **Both** | The daily breakdown and the total summary |

## Add a home-screen widget

Curbox has these widgets:

- **Screentime Widget** shows the total screen time for the current day.
- **Reels Widget** shows the number of short-form videos for the current day.

Open the **Usage** menu, and tap **Pin Widget**. Then, select a widget.

<Aside type="note">
Your home-screen app controls the final widget position and size.
</Aside>
